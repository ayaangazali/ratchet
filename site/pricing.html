Billing model

How billing works

Open source is flat zero — no seats, no metering, no telemetry. Planned hosted plans are per seat, billed monthly, cancel any time. Model usage is never resold: live runs call your own provider keys, so your inference bill stays yours and Ratchet's search budgets (nodes · wall-clock · dollars) cap it per run.

Pricing FAQ

Pricing questions

Is the free plan actually the full product?
Yes. The repo is the product. Paid tiers, when they exist, will add hosting and team workflow around the same verifier — never a stronger one.
Do I need a trial?
No — clone it and run make demo. If it isn't useful in sixty seconds, close the tab.
Refunds, discounts, overages?
Hosted plans will be monthly with no lock-in, so refunds rarely come up — cancel and you're done. No usage overages: model spend is on your own keys, capped by per-run budgets you set. OSS maintainers and academic labs will get Team free.
We're a large org — where do we start?
Start with the open-source version in a pilot repo (it's the same verifier), then open an enterprise inquiry with your compliance requirements.
